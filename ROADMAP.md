# Roadmap against the master specification

Version 0.4.0 delivers a usable native workbench for authorized source research. The roadmap
tracks remaining capabilities; no complete-master-specification or exploit-confirmation claim is made.

Delivered: native GUI/CLI; local/ZIP/public Git snapshots; checksum/provenance; bounded Git refresh
and source comparison; real Semgrep/Gitleaks/OSV/Trivy execution and public feed setup; per-scanner
history even with zero warnings; scoped explicit advisory correlation; human reviews; Python
assignment slices; local SQL laboratory; actual Qwen drafts/guards/cancellation/Windows arbitration;
RAM/NVIDIA telemetry; source-integrity report checks; portable schema 1–3 recovery; in-app schedules;
Windows x64 portable GUI/CLI EXEs with dynamic Qt, complete library sources/notices and checksums.

Remaining implementation order:

1. Harden Windows filesystem reparse/TOCTOU handling, trusted executable configuration/signatures,
   OS CPU/RAM/disk quotas, retention controls and signed/encrypted research archives.
2. More ecosystems and Java advisory cache setup; freshness policy, trusted custom rule management,
   broader framework coverage, semantic fingerprints, branch/interprocedural analysis and checkpoints.
3. Token-aware Qwen chunking, evidence citations, additional claim checks and explicit retry policy.
   Current source slices and ten Semgrep rules are bounded review signals, not broad semantic proof.
4. More trusted validation recipes and isolated local HTTP/Docker labs. Never run arbitrary imported
   source automatically. Current reproduction is restricted to the checksum-matched SQL fixture.
5. Full policy/authorization lifecycle, eligibility/range/prohibition editors and reviewed local
   active executors. External ZAP/Nuclei would require URL/DNS/redirect/port/category/budget controls.
6. Scheduler source-change checks, explicit advisory-refresh schedules, persisted notifications,
   fair queues, retention/retries, gaming pause and separately opt-in worker lifecycle.
7. Complete pt-BR technical translations, accessibility review, metric filters/plots and broader GUI
   end-to-end coverage; signed Windows distribution, installer and plugin process isolation.

Currently unsupported: private/SSH Git, submodules/LFS content/full Git history, automatic auth/IDOR/
business-logic detection, broad taint proof, exploit generation, novelty proof, bounty submission,
CodeQL/ZAP/Nuclei, arbitrary target test execution, Docker labs, OS quotas and cloud integrations.
